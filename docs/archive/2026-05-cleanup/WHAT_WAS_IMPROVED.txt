## What Agents Should Do

### Executor Agent
- Generate SVG with MINIMAL inline tspans
- Use tspans ONLY for line breaks (y/dy attributes)
- Share styling at parent <text> level
- Add data-consolidate="true" for simple text blocks

### Strategist Agent
- Review design spec for text formatting complexity
- Flag slides with critical fine-grained inline formatting
- Recommend consolidation mode in spec_lock.md

### Quality Gate
- Run svg_quality_checker.py to verify tspan efficiency
- Check: tspan-to-text ratio should be < 1.5
- Test generated PPTX: text should edit as continuous units

## Configuration Options

In spec_lock.md, add:
```yaml
text:
  consolidation: "auto"  # auto | compatible | none
```

- "auto": Smart consolidation (default, recommended)
- "compatible": Merge only if ALL styling identical
- "none": Keep all runs separate (preserve fine formatting)
