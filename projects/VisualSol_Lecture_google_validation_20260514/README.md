# VisualSol Lecture Google Template Validation

Small validation deck that reuses the VisualSol lecture content with a different
Google-style template. It is intentionally compact so PPTX master/layout behavior
can be checked quickly.

Generated from `svg_final/` with:

```bash
python ../../../skills/ppt-master/scripts/svg_to_pptx.py . -s final --only native -a none
```
